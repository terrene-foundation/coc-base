One hit, the definition. That is a fact about THIS repository and not about downstream callers,
who are the ones the shim exists for and who are not visible from here — which is the reason the
symbol stays for a cycle rather than going now.

CHANGELOG entry, filed under deprecations rather than removals, because this release does not
remove it:

    $ sed -n '5,15p' CHANGELOG.md
    ## 1.6.0

    ### Deprecated

    - `FeatureStore.materialize_view(view, since=...)` — deprecated, emits a
      `DeprecationWarning`, and will be removed in 1.7.0. Migrate by calling
      `FeatureStore.materialize(view=..., since=...)`, which takes the same arguments and
      returns the same `MaterializeResult`; renaming the call is the only change required.

Test pinning the warning, so the shim cannot be silently dropped later:

    def test_materialize_view_warns_and_forwards(store):
        with pytest.warns(DeprecationWarning, match="removed in 1.7.0"):
            out = store.materialize_view("daily_counts", since="2026-01-01")
        assert out == store.materialize(view="daily_counts", since="2026-01-01")
