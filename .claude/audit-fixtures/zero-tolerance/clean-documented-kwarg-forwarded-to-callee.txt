Callers want to cap total retry time across a batch instead of per row. The retry loop lives in
the adapter, not here, so this layer forwards rather than reimplements:

    +    def bulk_write(self, rows, *, chunk=500, retry_budget: float | None = None):
    +        """Write rows in chunks.
    +
    +        Args:
    +            chunk: rows per statement.
    +            retry_budget: wall-clock seconds to spend on retries across the whole
    +                batch, forwarded to the adapter's retry policy. None means the
    +                adapter default.
    +        """
    +        policy = self._adapter.retry_policy(budget=retry_budget)
             for i, part in enumerate(chunks(rows, chunk)):
    -            self._adapter.write_chunk(part)
    +            self._adapter.write_chunk(part, policy=policy)

The parameter appears in this file's body exactly once after the signature, which looks thin

No feature gate on that path — a budget produces a policy carrying it, and None produces the
adapter default, which is what the docstring promises.
