        def load(self, ref: ModelRef) -> Model:
            blob = self._store.fetch(ref.digest)
            if hashlib.sha256(blob).hexdigest() != ref.digest:
                raise IntegrityError(f"digest mismatch for {ref.name}")
            if ref.signer not in self._trusted_signers:
                raise UntrustedSignerError(ref.signer)
            if not verify_detached(blob, ref.signature, self._pubkey_for(ref.signer)):
                raise SignatureError(ref.name)
            return pickle.loads(blob)

Three gates before the deserialization, in this order: a content digest that the ref must match,
a signer allowlist, and a detached signature verified against that signer's key. The blob is
never attacker-controlled at the call — it has to round-trip a signature from a key in the
allowlist. So the finding is real as a pattern and not reachable as an exploit in the shipped
configuration.
