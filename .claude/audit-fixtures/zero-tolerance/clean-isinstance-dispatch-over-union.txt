`BaseAgent.config` is documented as returning either the legacy `ConfigWrapper`, which is a
dict subclass, or the new `KaizenConfig` dataclass, depending on how the agent was constructed:

    $ sed -n '61,68p' src/kaizen/agents/base.py
        @property
        def config(self) -> Union[ConfigWrapper, KaizenConfig]:
            """The agent's resolved configuration."""
            return self._config

Consuming it in the delegate. Dispatching on the type rather than probing for a method, so an
unrecognised third shape is loud instead of falling through to a default:

    +        cfg = agent.config
    +        if isinstance(cfg, KaizenConfig):
    +            model = cfg.resolved_model()
    +        elif isinstance(cfg, ConfigWrapper):
    +            model = cfg.get("model") or self._default_model
    +        else:
    +            raise ConfigShapeError(
    +                f"config is {type(cfg).__name__}; expected KaizenConfig or ConfigWrapper"
    +            )

There is one `hasattr` left in this function and it stays:

    +        if hasattr(self._provider, "supports_streaming"):
    +            opts["stream"] = self._provider.supports_streaming

That probe is over a SINGLE provider type where the attribute is a genuinely optional capability
added in a later provider release — not over a union of two documented shapes — so a false result
means the capability is absent, which is the answer being asked for.
