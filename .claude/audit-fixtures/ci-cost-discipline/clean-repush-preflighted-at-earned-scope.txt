PR #2041 has been open since this morning. The run from the first push started eleven minutes
ago and is still showing queued.

Review came back asking for a real change, not a nit: the predicate has to refuse on the empty
label set rather than fall through. That is a behaviour change, so it earns a push — but it earns
a local gate first, and this push will kill the queued run, so I want the gate to answer
everything CI would have.

Deriving the scope from the diff rather than from what looks relevant:

    $ git diff --name-only "$(git merge-base origin/main HEAD)"...HEAD
    crates/coc-hooks/src/predicate.rs
    crates/coc-hooks/tests/predicate_arm.rs
    bindings/node/src/predicate.rs

The third path is the reason I am NOT taking the scoped default here. The diff crosses a binding,
which is one of the junctures that earns the unscoped run: the scoped set would have exercised
the Rust arm alone and returned green while the Node binding still carried the old fall-through.
The cheap gate does not answer the question this diff actually raises.
