The secret scan is the one I would not skip under any amount of time pressure: an
oversized blob costs a history rewrite, a pushed credential costs rotation.

    git -C ... commit -m "checkpoint(UNREVIEWED): W3-codec mid-edit; may carry a live negative-control mutation"
    git -C ... push -u origin recovery/w3-codec-b
    git ls-remote --heads origin 'refs/heads/recovery/*'

The subject prefix is there so a merge gate can see mechanically that an unreviewed
checkpoint reached a PR; whoever resumes diffs against the base before trusting any
