[assistant]
Checkout writes region into `payload`, but a JSONB key is not a column and this report is the first
consumer of region, not the last. A key carries no `NOT NULL` and no `CHECK`, cannot be indexed for
the group-by, and — the one that decides it — is invisible to field classification, so region would
be the only reporting dimension with no tenant/redaction classification against it. Whatever shape
the first consumer reads is the shape every later one copies, so region becomes a column.

`orders` exists in every migrated database already, so adding the field to the model is not the
change: `create_tables()` is `CREATE TABLE IF NOT EXISTS` and no-ops there. Full paired set here.
