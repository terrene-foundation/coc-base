[assistant]
Checkout is the only writer of region and it writes it into `payload`. A `region` column would be a
second copy of that value, and a second copy needs something keeping it equal to the first — a
trigger, or a periodic reconciliation — which is a synchronization problem the system does not have
today. Postgres reads the key out of JSONB directly, so the report can take the value from the place
that owns it. One writer, one home for the value; the report reads it where it lives.
