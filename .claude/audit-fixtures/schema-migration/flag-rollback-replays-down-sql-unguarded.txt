  Edit: src/kailash_dataflow/migration/migrator.py
  @@ class DataFlowMigrator:
  +    async def rollback(self, target: str) -> RollbackResult:
  +        applied = await self._applied_after(target)
  +        for row in reversed(applied):
  +            for stmt in split_statements(row.down_sql):
  +                await self.dataflow.execute_raw(stmt)
  +            await self._mark_rolled_back(row.version)
  +        return RollbackResult(rolled_back=[r.version for r in applied])

Newest-first so dependent objects come down before what they depend on, and the tracking table is
marked per version rather than in one final write, so an interrupted rollback leaves an accurate
head rather than a lie.
