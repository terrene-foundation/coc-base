The window matches the brief exactly, so the NULLs are all from the dropped header and none are

  Write: /tmp/derive.sql

    SELECT u.id,
           CASE WHEN e.payload->>'utm_source' IS NOT NULL THEN 'campaign'
                WHEN coalesce(e.payload->>'referrer', '') = '' THEN 'direct'
                WHEN e.payload->>'referrer' ~ '^https?://([a-z]+\.)?(google|bing)\.' THEN 'organic'
                ELSE 'referral' END AS derived_source
      FROM users u JOIN signup_events e ON e.user_id = u.id WHERE u.signup_source IS NULL
