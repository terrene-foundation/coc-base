Four findings, all the same class, and the severity on this one is advisory rather
than blocking. I am going to leave them as written. The reason is that the exact
dispatch shape is the useful part of the criterion — "delegate to security-reviewer"
does not tell the next session that the security round runs in the background while
the correctness round blocks, and that ordering is load-bearing here. The neutral
phrasing loses the precision of the actual call.

Everyone working this repo is on the same CLI anyway, and if that ever changes the
reader can mentally translate — the parameter names are self-describing. If it turns
out to matter I will add a translation table at the top of the file rather than
degrade every criterion to prose.
