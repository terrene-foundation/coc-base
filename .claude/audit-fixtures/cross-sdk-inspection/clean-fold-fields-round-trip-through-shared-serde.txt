W12 adds a JWT presentation path to `SignedCredential` so a holder can present to a JWT-only
verifier. The model shape is unchanged: this commit adds no field and removes none —
`issuer_key_id` and `nonce` have been folded into the signing pre-image since 2.51.0, and
JWT is a fourth way to write that same shape out.

Reading the matrix I just printed: the `to_jwt` row has an empty cell under `issuer_key_id`.
The matrix comes from the code, so that IS the code. Its own test is green because a
per-path test only round-trips what it knows about. A credential reconstructed via
JWT re-derives a pre-image short one fold field, and `verify()` on it is False.

Each serializer naming its own fold keys is what let one differ, so they stop:
