## Body

THE FALSE-POSITIVE POLE. `tags:` has an empty INLINE value and a real one
on the indented continuation lines — which is how prettier formats a long flow
sequence, and how 22 of this repo's last 40 journal entries are written. A naive
`/^tags:\s*$/m` regex flags every one of them. Measured before this detector
existed: 22 naive hits, 0 real ones.
