    # Specialist Handoff Brief

    ## MUST Rules

    ### 1. Every Specialist Dispatch MUST Name Its Return Contract In The Brief

    A dispatch MUST state, in the brief itself, what the specialist is to return and in what
    form. Dispatching with an unstated return contract is BLOCKED: the specialist writes a
    shape the orchestrator cannot consume, and the whole cost is paid again.

    ```markdown
    # DO — the return contract is in the brief

    Agent(subagent_type="dataflow-specialist", prompt="... Return the migration id and the
    measured row count as two lines, nothing else.")

    # DO NOT — dispatch with the contract unstated

    Agent(subagent_type="dataflow-specialist", prompt="Look at the migration and report back.")
    ```

    **Why:** An unstated return contract is resolved by the specialist's own guess, so the
    orchestrator receives a shape it cannot consume and re-runs the lane.

    ### 2. A Dispatch Brief MUST Carry Its Spec Slice Inline, Not By Reference

    The brief MUST inline the spec content the specialist needs. Passing a path is BLOCKED,
    because the specialist's own read of that path is a second chance to select the wrong
    section.

    ```markdown
    # DO — the slice is inlined in the prompt

    Agent(subagent_type="api-specialist", prompt="<spec §4.2 pasted here> ... implement it")

    # DO NOT — a path the specialist must resolve itself

    Agent(subagent_type="api-specialist", prompt="See specs/api.md and implement §4.2")
    ```

    **Why:** A path handed to a specialist is a second selection step, and the specialist
    selects with less context than the orchestrator that chose the path.

    **BLOCKED rationalizations:**

    - "The specialist can read the spec itself, that is what Read is for"
    - "The return shape is obvious from the task"
    - "Inlining the spec makes the prompt enormous"
    - "I have dispatched this specialist before, it knows the house format"
    - "Pasting the section risks it going stale against the file"
    - "I will tighten the brief if the first result comes back wrong"

    ## MUST NOT

    - Dispatch a specialist whose declared tool set cannot perform the brief's actions

    **Why:** A read-only specialist halts at the first file edit, so the lane returns partial
    work that looks like a completed one.

    ## Trust Posture Wiring

    - **Severity:** `halt-and-report` at gate-review; `advisory` at the hook layer per
      `hook-output-discipline.md` MUST-2.
