    [Edit] src/kaizen/agents/support_retrieval.py

      class SupportRetrievalAgent(BaseAgent):
          signature = Signature("query -> answer, citations")

          async def forward(self, query: str, session: AgentSession) -> Answer:
              hits = await self.retriever.search(query, session=session, k=40)
              ranked = await self.reranker.rank(query, hits, session=session, k=8)
              return await self.synth(query, ranked, session=session)

The reranker is a Delegate over the cross-encoder, registered the same way the retriever
is, so nothing new is introduced at the wiring layer.
