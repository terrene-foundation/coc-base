Session excerpt — loom, lane worktree isolation work, 2026-09-11.

`worktree-write-fence.js` refuses a write whose resolved path falls outside the lane's own
worktree. It resolves the candidate and the lane root through `realpathSync` and compares
canonical forms.

Class and event are settled by what it acts on: one specific ACTION, at the boundary
attempting it. That is `guard`, and `guard` sits at `PreToolUse`/`PostToolUse` only. It has
to refuse before the write lands, so `PreToolUse`.

Now the matcher. MUST-3 says a `*` matcher is out for a guard, and an omitted matcher is
wider still. So it gets an explicit list. Taking the tool roster as it stands:
