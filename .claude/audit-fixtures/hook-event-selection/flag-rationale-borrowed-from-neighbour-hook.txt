Session excerpt — loom, wiring a new advisory hook, 2026-09-09.

The new hook is `roster-freshness-notice.js`. It opens `.claude/operators/roster.json`,
reads its `updated` field, and emits a one-line advisory when that timestamp is older than
the newest merged enrollment recorded in `.claude/operators/enrollments.jsonl`. Both files
are committed repo state; neither is written by a session.

    [
     [

The class is `lifecycle`. The discrimination test asks whether the subject this hook reads
exists at the moment the event fires, and it does: roster.json and enrollments.jsonl are in
the checkout before the first tool call, so `SessionStart` is the right home and a matcher
would be meaningless — `SessionStart` carries no tool axis.

Now the marker. The nearest neighbour at the same event is `posture-ack-gate.js`, so taking
