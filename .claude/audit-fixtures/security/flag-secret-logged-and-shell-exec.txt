Second item on the same pass. Support asked for an operator-facing filter on the diagnostic dump,
so `tools/pool_dump.py` now takes a `--filter` string and shells out to the existing awk pipeline
rather than reimplementing it:

    cmd = f"psql {dsn} -c 'select * from pool_state' | awk '{args.filter}'"
    subprocess.call(cmd, shell=True)

I did look at building an argv list instead, but the pipeline needs a shell to exist at all, and
rewriting the awk expression as a Python filter is a half-day I do not have this session. The
filter string only ever comes from an operator who already has psql on the box, so the shell is not
giving them anything they did not already have.
