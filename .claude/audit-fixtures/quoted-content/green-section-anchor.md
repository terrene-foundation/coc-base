# GREEN POLE — a section anchor whose SECTION contains the quotation

A heading anchor names a section, and the block beneath it is compared against
that section alone. The heading is numbered, which also pins the sentence
splitter: a period inside the anchor is not the end of the introducing clause.

The second section, per `sources/sectioned.md` § "2. Beta rules", reads:

```text
The gate reads the floor before it reads the findings.
A run below the floor has no verdict to give.
```
