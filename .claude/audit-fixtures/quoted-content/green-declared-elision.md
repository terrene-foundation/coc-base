# GREEN POLE (no-false-positive) — a DECLARED elision

The same material the RED omission pole drops, dropped again — but ANNOUNCED.
A declared elision converts `undeclared-omission` and `undeclared-truncation`
to a pass, because the reader has been told the block is partial.

This pole is the half that decides whether the gate SURVIVES rather than
whether it FIRES: a checker that reds on every legitimately-abridged quotation
is red on every commit forever, and a red-forever check is the one an operator
learns to ignore.
