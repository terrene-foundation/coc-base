## MUST-6 — why a regex over prose cannot be made safe

The surface-form space of natural language is unbounded, so every regex over it is a finite net over an infinite space and a NEW misreading is mathematically guaranteed, not merely likely — the failure mode is a silently FABRICATED value, which is worse than an error because it is reported with the grammar of a measurement. Emitting the value structurally at the source closes the class BY CONSTRUCTION: there is no prose left to misread. Evidence: nine independent adversarial rounds against one prose verdict-parser each found a NEW form it misread (intervening-word negation, verb-vs-status confusion, hard wraps, CRLF, markdown emphasis between the words, GFM trailing backslash, HTML `<br>`); the durable fix replaced ~160 lines of parser with a ~25-line structural read of an emitted marker. The canonical-position half is separately load-bearing: three further rounds surfaced a doc EXAMPLE, then a prose-embedded mention, then an INDENTED code block each read as the authoritative verdict.
